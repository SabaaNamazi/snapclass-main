# SnapClass

SnapClass is an AI-powered classroom attendance system that automates attendance using **face recognition and voice biometrics**.

Teachers can create subjects, share class access through **QR codes**, enroll students, capture classroom photos for **AI-based face attendance**, and use **voice recognition** to identify students. Students can register their face and voice, join classes through QR-based enrollment, and track their attendance records.
